# Site conventions

This file lives in `_notes/`, so it is treated as a living document rather than
as a dated blog post.

## Adding an image

Put the file in `assets/images/`, then use:

```markdown
![A useful description](/assets/images/example.jpg)
```

Use images rarely and only when they carry information.
